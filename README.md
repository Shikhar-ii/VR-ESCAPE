# VR-ESCAPE
Virtual Reality design for the theme of escape room

## Cyber Escape: The Last Signal

A responsive, browser-based escape room set inside the compromised Helix Research facility. The experience is implemented with vanilla HTML, CSS, and JavaScript; there is no build step or backend.

### Play

Open `index.html` in a browser. An internet connection loads the facility photograph and Google Fonts; the game itself runs locally in the browser.

### Mission

- **Access Control:** recover the incident date and terminal passphrase, collect the staff badge, then release the airlock.
- **Network Investigation:** identify the suspicious IP, trace the internal pivot, and decode the captured service.
- **System Recovery:** decrypt the attacker’s directive, route the emergency power bypass, and restore the core.

Inspect the highlighted objects in each room. Incorrect answers cost 15 seconds. Use **Request a hint** (or `H`) for a clue, the pause control to suspend the timer, and the room map to revisit unlocked zones. Evidence and solved challenges persist while the mission is active.
